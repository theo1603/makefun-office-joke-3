One-line office joke writer: a Python program that writes a single original joke about office life (121 characters, one line) to `/output/entry.txt` for make.fun's "The Funniest Office Joke, Judged Head to Head" bounty, $2 in USDC. The joke: a calendar so full its owner tries to book a meeting with themself — and declines it, already in a meeting with themself. Deterministic, dependency-free, no network.

## Run it

```sh
python3 main.py
```

`main.py` writes the joke to `/output/entry.txt` (121 characters, one line).
